# OneSlot India

Build OneSlot, a mobile-first dark premium web app for India’s recurring local services marketplace: gyms, salons, tuition/coaching, sports academies, and dance/yoga. Build consumer app and provider dashboard as connected experiences within one project, with Supabase database and auth. Use the supplied data model, seed 15–20 realistic providers across categories with plans and a week of capacity-aware slots. Implement real data-driven browsing/search/filtering, provider creation and listing, capacity-safe booking transactions, subscriptions with session decrementing, reviews that update provider ratings, provider CRUD for services/plans/availability, dashboard booking/customer/report views, and role-based consumer/provider routing. Mock OTP delivery and payments but create real auth/data records. Follow the exact dark District/Zomato-inspired visual direction: near-black background, charcoal rounded image-forward cards, sparse coral #FF3F42 accent, Inter typography, sticky location/search header, horizontal rails, mobile bottom nav. Ensure every named consumer and provider screen/flow works, responsive but mobile first.
